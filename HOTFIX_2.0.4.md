# V2.0.4 - icon picker and compact task editor

- Adds an explicit top-layer atlas picker so it cannot be obscured by the task modal or XP bar.
- Adds a dedicated click handler to the Create Task icon button.
- Improves error visibility if the icon picker fails.
- Fixes crop preview text for selections that do not have a fixed 10x10 cell number.
- Tightens task editor spacing, input heights and button layout on phones and desktop.

Deploy by replacing the existing website files. Hard refresh after GitHub Pages deploys.
This patch has not been verified against the live Supabase instance.
