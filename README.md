# Our Quest V2.0 Cloud Edition

Includes all four icon sheets, tasks, quests, coupons, goals, atlas crop editor, safe-area header spacing, always-visible XP progress, goal archive/delete, task hide/archive and optional cloud login/sync.

**Read SETUP.md first.** Run schema.sql in a new Supabase project, edit config.js and publish over HTTPS. This is a trusted-two-user cloud release, not a security-hardened transactional game server.

V2.0.1 hotfix: restores loginClaims and daily reward defaults when loading cloud data, and prevents a blank sign-in screen on rendering errors. Replace hosted files and hard-refresh.
