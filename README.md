# Our Quest V1.7.0

## Changes
- All three original icon sheets replaced with transparent, grid-free source artwork.
- Fourth sheet Grand Adventures added.
- Existing free-position icon selection retained for tasks, coupons, goals and milestones.
- Atlas Library preview no longer draws a fixed 10×10 overlay.
- Upload icon sheets with flexible layouts and transparent padding.
- Visible version updated to V1.7.0.

## Installation
Back up your V1.6 data first. Unzip all files and replace the hosted app files at the same URL. Do not clear browser storage. For an installed PWA, reopen or refresh to retrieve the new assets.

## Notes
This is a local prototype. Supabase synchronization is not connected. The three original sheets are replaced by their existing grid-free source artwork; no generative restoration or inpainting was required. Existing crop references are preserved, but small vertical adjustments may be useful because the artwork was padded to square dimensions. Uploaded custom atlases remain stored in the browser and are not included in JSON exports.
