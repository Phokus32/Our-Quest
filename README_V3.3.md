# Our Quest V3.3 test release

Upload all files and the assets directory to the existing GitHub Pages repository. Back up your live Supabase data before installing. Existing data records are not intentionally reset. V3.3 adds the admin/player display toggle, coupon editing with repeat pricing, seasonal task visibility, completion filters, category editing with atlas icons, consistent crop rendering and a goal-editor initialization repair.

**Testing limits:** JavaScript syntax and ZIP integrity are verified. Live Supabase synchronization, mobile Safari and all browser interactions are not fully tested. The legacy shared JSON backend is not transaction-safe or server-authorized.
